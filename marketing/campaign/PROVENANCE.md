## Preserved original specification

- Premium widescreen product-launch composition for technical/product audiences.
- Recognizable products carry most of the visual focus, with unequal scales and deliberate overlaps.
- A large operations platform anchors the scene, with a standing phone, detailed game world, an assistant's reviewed action and spreadsheet-to-document automation.
- Studio identity and character sheets connect the game to its origin.
- Indigo/teal glass-and-metal surfaces, turquoise accents, ivory typography, warm coral and sunlit coastal terrain.
- Main Ukrainian headline: “Задумай масштабніше.”
- Supporting Ukrainian line: “Від першої ідеї до продукту, що розвивається.”
- Brand label: “AGENT SYSTEM 5.0”.
- Scope: applications, games, chatbots, platforms and custom agents.
- Conceptual-capability label, with no claim of actual customers, orders or release.
- Avoid abstract orbs, robots, provider logos, giant arrows, equal-card grids and exhaustive implementation copy.

The nine later Ukrainian materials extend that one artwork. The current English counterparts localize the same ten Ukrainian compositions; they are not ten unrelated design concepts. Preserve objects, framing, layout, colors, game/studio identity and state meaning while translating all readable text. My Day and Assistant are localized display names; Global Logistics and Sunridge Studio remain stable.

## What each kind of evidence proves

All ten Ukrainian source hashes are fixed in `campaign.json`. Paired IDs and dimensions establish correspondence, not pixel identity across language edits. Visual/text review must assess whether each English edit preserves non-text content and translates visible copy. Any unverified residual drift must remain a limitation; it must not be concealed by a matching file hash.

PDF pixel verification compares each full PDF image against its own locale's canonical PNG. This proves the exporter preserved the artwork, not that English and Ukrainian PNGs have identical non-text pixels. Compact PDFs intentionally use JPEG delivery encoding. Repository galleries reference local PNGs; standalone delivery HTMLs embed those same source bytes.

Canonical skill source hashes, installed icon identity, host installation, runtime execution, product deployment, publication and owner design acceptance are separate statuses. This campaign does not modify product state or certify the illustrated outcomes.
