# Support statement — 1.0.0-rc.1

Owner-review draft. Before sale, the verified seller must add a working
private support contact, staffed hours, languages actually served, and the
response expectations it can meet. A public repository issue can report an
installation bug without personal details; it is not the private purchase
support channel and carries no response SLA.

Included scope: delivered documentation, setup guidance, package integrity
and compatibility diagnosis, and reproducible defects in a supported edition.
The buyer supplies an order reference, product version, edition, platform,
and a redacted diagnostic summary. Never request host keys, model tokens,
private chats or full customer projects.

Custom product development, third-party outages, model subscriptions, API
fees and storefront accounts are separate. Perpetual acquired-major use
does not mean perpetual staffed human support or future service availability.
Do not advertise a response time until the seller confirms it. Preserve the
version of this statement accepted for each order.
