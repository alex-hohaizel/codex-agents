# Review channel-ready materials

The [matrix](compatibility.json) records each delivery format and its limits.
The [submission dossier](SUBMISSION_DOSSIER.md) points to current primary
platform rules. The buyer package and seller-local test redemption flow are
the required independent route. No external listing or payment is implemented.

The two single-file coaching exports are intentionally narrower than the
native Codex package. They preserve planning/handoff review from supplied text;
they do not install roles, execute native scripts or provide a Mac workbench.
Their source is in this directory and the canonical build emits exact copies.
Local format and model-task proof does not establish marketplace acceptance.
