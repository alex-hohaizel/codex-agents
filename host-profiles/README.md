# Host production profiles

The Codex profile is a managed addition to supported global `AGENTS.md`, preserving existing instructions outside its marked block. `scripts/install_host_profile.py` audits exact source/target hashes, applies a reviewed plan with backups/journal, verifies and supports conflict-aware rollback. It updates the twelve supplied bounded role profiles to the exact release model and effort and preserves their external-effect restrictions. Exact managed predecessors migrate automatically. A foreign selector or unqualified lower effort requires reconciling the private audit diff before updating the profile.

The installer never changes active product states. Check actual instruction loading and a bounded task separately from file installation. Existing chats may retain earlier loaded instructions; a new/resumed host must read current sources. Work audit/installation is deferred and no automatic Work loader or parity is claimed. Vendor cache files are not patched.
