# Host production profiles

The Codex profile is a managed addition to supported global `AGENTS.md`, preserving existing instructions outside its marked block. `scripts/install_host_profile.py` audits exact source/target hashes, applies a reviewed plan with backups/journal, verifies and supports conflict-aware rollback. It also updates the twelve supplied bounded role profiles without changing their model selection or external-effect restrictions.

The installer never changes active product states. Check actual instruction loading and a bounded task separately from file installation. Existing chats may retain earlier loaded instructions; a new/resumed host must read current sources. Work audit/installation is deferred and no automatic Work loader or parity is claimed. Vendor cache files are not patched.
