# Shared production standards

These are reviewed authoring sources for the self-contained resources bundled with every core skill. Run `python3 -B scripts/materialize_standards.py --check` to detect drift or omit `--check` after an authorized source change to materialize exact copies. The runtime does not depend on this sibling directory.

The compiler verifies declared context and byte dependencies. It does not certify quality, consent or task completion. Medium-specific output and cold-receiver review remain required. Existing native state formats and product identities stay independent of the suite release number.
