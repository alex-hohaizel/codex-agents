# Brief and resume through Atelier Orchestrator

Use the [topic catalog](../assets/briefing-topics.json) for a new material decision or recovery. Read the original request, the exact project source and current checkpoint first. A clear, authorized routine task can proceed through the ordinary direct or specialist route.

For a brief, describe the requested outcome and any material decision blocking it. Confirm the owner, project, affected requirements, available route and evidence due. Compare direct work, an existing specialist, a project agent and construction only where the choice changes the result or its constraints. Keep execution of the original task separate from construction or adoption.

For a resume, keep the current project, approved scope and unresolved or deferred obligations. Read the exact checkpoint and follow the evidence chain to current artifacts and runtime. Check an active pause, authority changes and uncertain external receipts before dependent work. Continue independent steps within the current authorization.

For a handoff, bind the requested result, current source pins, ownership, permitted effects, target environment, acceptance and exact return route. Retain the chosen project language and original literals. The [interaction protocol](interaction-protocol.md) gives the read-only CLI for supported native ledgers. For another ledger, use the verified domain procedure with the same source and evidence requirements.

Close the current scope with the actual result, due evidence, pending work and next authorized action. Distinguish a prepared task from a dispatched one and a returned result from owner acceptance.
