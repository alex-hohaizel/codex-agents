# Route an interactive prototype, template, import or tracker tree

Ask the experience owner to bring exact reviewed DESIGN and EXPERIENCE inputs
when the interaction is a decision. Use the installed App Atelier Experience
skill to build a browser walkthrough, and keep browser interaction evidence
with the build and QA handoff. Test the ordinary path and the blocking path.

Review and stage existing skill modules with Agent Foundry. Preserve the original
project and personal overrides until the selected migration is verified in a
separate directory and exercised by the actual host.

For document templates or tracker trees, use a verified Codex Agent System
checkout that supplies the versioned helpers and the matching operator guides.
Read `docs/technical/DOCUMENT_TEMPLATES.md` to bind and review a reusable
draft template or companion. Read `docs/technical/TRACKER_SYNC.md` and its
provider contract before any issue change. Authority for a local plan does
not authorize an external write. Keep the original approved preview and
journal when a request outcome is unknown. Reconcile before another effect.

All four routes continue the existing project record. Keep unmatched provider
fields, missing decisions, stale sources and awaiting acceptance visible.
