# Change log

## Repository 1.0.0 — 2026-11-07

Baseline reusable suite: **Agent System 5.0.0**, 33 stable skills. This repository release does not modify their canonical behavior or existing icons.

- Import verified reusable source, portable updater and original tests; omit private project source, chat history and prior personal installation archives.
- Add complete onboarding for Work and Codex, practical use, both-direction project handoff, recovery and upgrade/rollback guidance.
- Add English documentation plus equivalent Ukrainian, German, Italian, Spanish, French and Simplified Chinese guides; persist the chosen interaction language.
- Add permanent publication rules, requirements traceability, release records, migration templates, archive builder and CI validation.
- Add an optional repository maintenance skill, separate from the canonical suite.
- Add ten comparable visual marketing concepts with identity preservation rules; final campaign selection remains pending.

**Existing users:** adopt repository governance and project context using [the migration](releases/migrations/5.0.0.md). A previous 5.0.0 installation need not be overwritten solely to obtain this documentation release. Already generated agents need their own compatibility check; they do not inherit a toolkit update automatically.

**Future releases:** add an entry stating changed versions, concrete behavior changes, affected users, exact source-to-target migration, validation evidence and rollback consequences. Update the general guide whenever the normal workflow changes.
