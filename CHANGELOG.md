## v1.8.0 — universal installation

Adds one browser-based setup workflow and ready packages for Windows/macOS/Linux
on x64 and ARM64, with bundled pinned Python/Node and the built local workbench.
Preserves the source CLI and existing update journals, skills, roles, icons,
project environments and commercial draft rights. Adds native package/browser
acceptance, interruption recovery, Windows ACL/path/lock safety, source ZIP HTML
navigation and complete installation guidance.
