# Почніть з одного запиту в Codex

[Повний український посібник](GUIDE.md) · [Встановлення або оновлення](../INSTALL.md) · [Можливості системи](../../README.md#what-you-can-do) · [Усі розділи](../INDEX.md)

Сформулюйте результат так, як пояснили б його колезі. Для першої вправи
достатньо однієї папки й одного результату, який можна перевірити. Для
довшого проєкту є спільний маршрут: уточнити правила, підібрати команду,
перевірити результат і залишити докази та наступний крок.

## 1. Підготуйте Codex

Якщо навички вже встановлено, відкрийте свіжий чат у пробній папці.
Спробуйте вибрати `$agent-foundry` зі списку навичок, якщо ваш Codex його
показує. Запитайте, який шлях і версію бачить ця сесія. Самої назви у
відповіді недостатньо: звірте її з установленим шляхом і [виконайте контрольну задачу](#2-побачте-перший-результат).

Для нової установки відкрийте [офіційні команди](../INSTALL.md). Вони
фіксують версію, перевіряють підписаний архів, показують план і зберігають
журнал для відновлення. Якщо вам зручніше говорити з Codex, вставте
цей запит у звичайний чат ще до встановлення навичок:

```text
Проведи мене українською через встановлення Codex Agent System.
Візьми чинну інструкцію з alex-hohaizel/codex-agents, docs/INSTALL.md.
Спочатку перевір, що вже встановлено і який реліз є стабільним.
Поясни, який результат я маю побачити після кожного кроку.
Покажи план і цільову папку; не замінюй встановлені файли до мого прохання.
Якщо певний крок у чаті недоступний, покажи точну команду та як звірити результат.
```

Встановлення використовує локальні інструменти й дозволи комп’ютера.
Якщо хост не може підготувати аудит чи застосувати план, використайте
команди з інструкції або зверніться до адміністратора цього комп’ютера.

## 2. Побачте перший результат

Створіть окрему пробну папку. Додайте `README.md` із заголовком
`# Cheklist` і `notes.txt` із будь-яким рядком. Відкрийте свіжий чат
Codex у цій папці та вставте:

```text
Виправ Cheklist на Checklist лише в заголовку README.md.
Перевір notes.txt до і після правки. Покажи новий заголовок
і назви файл, який змінив. Підтвердь, що notes.txt збережено.
```

Очікуваний результат: `# Checklist`, один змінений файл і незмінні
нотатки. Для автоматичної звірки є [нативна контрольна задача](../../evaluations/README.md#run-a-focused-native-codex-canary).

## 3. Виберіть свою точку входу

| Що хочете зробити | Звідки почати |
| --- | --- |
| Виконати відому роботу | Відкрийте потрібний проєкт у Codex та назвіть задачу або [навичку](../CAPABILITIES.md#all-skills-and-roles). |
| Почати з однієї розмови та зібрати команду | Окремо встановіть [Atelier Orchestrator](../INSTALL.md#optional-components). У новому чаті напишіть `$atelier-orchestrator`, мету, джерела та обмеження. |
| Створити спеціаліста для повторюваної роботи | Почніть із `$agent-foundry`: опишіть, що він отримує, що повертає, де може діяти й на якій першій задачі його перевірити. |
| Працювати з локальними проєктами у вікні браузера | [Зберіть і запустіть Agent Atelier для Mac](../../apps/agent-atelier/README.md#build-and-launch). Це окремий локальний інтерфейс. |

[Подивіться схему роботи команди](../../assets/marketing/release-1.7/workflow-uk.svg)
і [пройдіть наскрізний приклад](../technical/END_TO_END.md). У ньому
директор тримає мету, продукт і архітектура узгоджують правила,
розробники ділять роботу, а окрема перевірка оцінює інтегрований результат
перед рішенням про випуск.
