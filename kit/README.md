# Portable core

The kit contains the 33 managed skills for Codex. Agent Foundry and Design Specialist Skills build reusable agents or skills. App Atelier, ChatBot Atelier, and Game Atelier cover their respective product lifecycles. Each skill includes its entrypoint, operating references, templates, and applicable helpers. The current component record identifies the suite version. [Component versions](../releases/current.json)

Follow the installation guide to obtain and verify the official CODEX package, audit the intended skill directory, apply the reviewed plan, and check that fresh Codex sessions resolve the installed skills. Keep the plan and the returned recovery journal with your backups. [Install and verify](../docs/INSTALL.md)

Use a separately prepared and approved project-agent kit with the portable project installer. Check the exact project and preserve its current state, requirements, decisions, and ownership. Run a bounded task in the actual project after installation. [Portable integrity and tools](PROVENANCE.md) · [Engineering guide](../docs/OPERATING_MODEL.md)
