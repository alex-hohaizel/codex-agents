# Assets: виробництво та семантична інтеграція 4.0

## Вхід і inventory

Прийняти T contracts або вузький authorized spike, exact model/state/event IDs, accepted originals, camera/input/phone framing, budgets/rights й target profiles. Вивести required state/variant/clips/cues/screens/locales/music transitions із agreed scope; не замінювати inventory кількома красивими examples.

## Робочий алгоритм

1. Зв’язати потрібний output із operation ID, ToolCapabilityRecord і ProductionRecipe. Перевірити реальні schema/catalog/parameter bindings; prompt чи назва моделі не доводять editable layers, rig, MIDI/stems або native export.
2. Вибрати actual representation: raster/frame, cutout/skeleton, vector, 2.5D/3D за задумом. Зафіксувати source→edit→export→import→consumer steps, versions, права/ліміти, expected outputs, verification, repair/stop/cost.
3. Для кожного ребра заповнити SemanticTransformation: units/axes/scale/pivot, timebase/root motion/contact markers, color/alpha/materials, audio rate/channels/loop/tails, preserved invariants, intentional loss й validator. Format-valid не означає semantic-valid.
4. Виробляти й зберігати actual source та output hash; для stochastic provider записати доступні params/model/job/seed. Не обіцяти bitwise regeneration, коли provider цього не гарантує. Невідомий job outcome reconcile до повтору.
5. Технічно перевірити source reopen/export та import-lint; предметно переглянути силует, deformation, feet/weapon contact, readable cues, full UI states, localization, listening/mix/loops. Перевірка заголовка файла не є переглядом чи слуханням.
6. Зібрати actual scene разом із build: input/camera, physics/hit windows, animation/VFX/SFX/haptics, resource/reward/save. Перевірити normal/peak/failure/cancel/death/return за fit, lower tier і доступні sensory equivalents.
7. Зберегти AssemblyEvidence для exact scene/build/config/inputs, фактичні modalities й unresolved due proofs. Окремий reviewed clip не доводить правильний контакт у збірці.

## Точні предметні вимоги

| Вид | Виробничий контракт і тест |
|---|---|
| 2D | Layer/pose registration, silhouette, pivot, frame duration, atlas padding/bleed, filter/alpha/color; feet/contact/cancel у сцені |
| 3D | Editable mesh, hidden surfaces/topology/UV/PBR, units/axes, skeleton/bind/weights, stress poses, attachments, retarget/root policy, LOD/collision budget; actual import |
| Death/crash/parts | Alive/disabled/downed/dead/cleanup clips за fit, break/part cues, transform ownership controller↔ragdoll↔respawn, bounded debris; representation не вирішує gameplay outcome |
| UI/locales | State/empty/error/pending/owned/expired/restore, string IDs/plural/placeholder/context, font/glyph/RTL за мовами; price/cancel не ховаються |
| Music | Motifs/states/tempo/meter, actual editable session/stems де потрібні, aligned loops/tails/transition rules, runtime mix/voice budget і слухання |
| SFX/haptics | Confirmed simulation event→material/part/force feature/outcome→variant/priority/dedup/start-update-end; no-haptic/mute equivalent; physical-device proof окремий |

Immediate hit cues походять від authoritative simulation outcome й не чекають disk/cloud. Critical reward/purchase/victory success presentation відповідає своїй authoritative durable/verification boundary. Animation/audio callback не видає нагороду й не повторює damage.

## Coverage та repair

Кожний required state має produced output або визначене intentional reuse/silence із rationale. Cache key включає semantic inputs, recipe/model/importer versions; змінені edges інвалідують похідні, immutable accepted original зберігається. Два однакові невдалі ремонти → diagnosis/route change; відсутній rig capability не лікується повторенням prompt.

## Вихід

Sources/exports/catalogue, operation/recipe/transformation/attempt refs, asset→runtime consumer mapping, exact hashes/versions/rights, actual import/assembly/listening/view/device evidence, coverage denominator, gaps/owner/due/closure. New receiver відтворює supported route без попереднього чату. Не називати план або generated screenshot готовою native-грою.
