# Каталог матеріалів і передача в runtime

## Finite scope

Inventory is derived from approved GDD/content/screen/event data. Every category has required/produced/exported/reviewed/runtime-tested counts and missing IDs; denominator does not shrink because a tool is missing. An absent-by-design category has rationale and review, not a blank cell. Reuse is allowed with explicit consumer mapping; duplicate bytes renamed as new characters/animations do not prove semantic variety.

For procedural content list full authored vocabulary, executable grammar/config and representative/boundary outputs; don't enumerate infinite instances. For UI list state families and covered component mappings; actual special layouts/states require their own sources/targets. For audio list all tracks/states/transitions/SFX families and intentional silence.

## Per-item record

Catalog є проєкцією current game model: додати source path/revision/hash, model object/state/event IDs, scenario IDs і runtime binding IDs. Не вести в item metadata інші числа damage/cost/unlock, ніж canonical rules. Construction/export values мають derivation recipe. Для image proposal, source preview, actual native capture і physical-device observation зберігати різні evidence origin/modality/stage; record не створює доказ сам собою.

The exact container schema is defined by shared handoff; domain catalog can use the bundled starter form. Each item needs:

- stable ID/category/version, design requirement and consumers, variant/clip/state coverage;
- exact approved baseline/choice refs and hashes, fixed properties/allowed envelope;
- real editable source file(s), source format/tool/version, dependencies and hashes;
- actual runtime export(s), format/import settings/units/axes/color space/compression/loop markers and hashes;
- production recipe/log, generator/config/seeds when used, raw inputs/outputs, tool invocation/result;
- previews/context assemblies for relevant modalities, rights/provenance/license;
- technical/creative/sensory acceptance criteria, actual review refs, missing evidence/owner;
- runtime integration receipt by build/platform/device when executed.

Do not put opaque arbitrary metadata in the canonical package manifest if its schema does not allow it; include a domain catalog file and refer to it through the shared contract. Text with `.fbx` extension does not become mesh; PNG of a waveform does not become audible music; parameter table without executing generator/source is not generated material.

## Source → export → import → capture

Preserve immutable creative source/export baseline. Runtime derivatives (engine import caches, compression, platform encodes/LOD) link to exact approved source/export and recipe. Capture receipt references scene/state/seed/camera/time/resolution/quality, material hashes, engine/importer/plugin versions, actual build hash/device and observed result. Do not bind a new capture to an old build or reuse a source preview as native runtime proof.

If a platform adapter fails, report that platform separately. Android capture does not verify iOS color/audio/input/performance. A simulator can verify scoped layout/logic but not actual haptic/thermal/touch latency. A release artifact is only present when actual bytes exist and signing/export state is accurately recorded.

## Studio carry-forward

Carry exact studio ID/name/legal display data, approved logo variants/fonts/license/support/privacy references and allowed placements. Copy relevant source assets and metadata unchanged with hashes, not a newly generated approximation. Keep confidential account/secrets out of game payload. Game-specific style and studio brand coexist through explicit placements, not uncontrolled visual blending.

## Consumer intake

Consumer opens required sources/exports, verifies relocatable paths/dependencies, imports representative and risky categories, checks scope/baseline bindings and reports accepted/scoped/blocked with missing IDs. Full generation recipes are not a substitute for required delivered material. If edit/export license or source availability prevents portability, disclose exact restriction and lawful restore path; don't call the package fully self-contained.

## Semantic coverage closure

До denominator додати death/crash/disabled/part-break/cancel, status stacking, interaction start/update/end, locality/quality/sensory alternatives за actual rules. Reuse не потребує зайвих декартових копій, але кожний consumer/state має mapping. Для generated content потрібні всі authored modules і grammar bindings, а не нескінченний список інстансів.

Consumer intake перевіряє не лише файли, а scale/axes/contact markers/collision/time/loop/color та actual whole-scene behavior. Accepted source, exported derivative, imported resource й native capture мають distinct identity. Missing production output не стає delivered завдяки recipe.
