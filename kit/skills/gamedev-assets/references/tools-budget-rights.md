# Реальні інструменти, витрати та походження

## Capability first

Discover currently available connectors/skills/CLI; prefer sufficient existing integrations. Check operation separately: generation, native editable source, rig/animation, export, download, license, engine import, audio audition, native build/capture. A known product is not an installed capability; a connected app does not imply access to every operation. Follow runtime instructions and explicit user environment preference.

Common candidate toolchain: Blender for modeling/rigging/animation/baking; Krita/GIMP/Inkscape for 2D/vector; engine-native UI/shaders/particles; Audacity/Ardour/LMMS or another lawful DAW/editor for composition/edit/mix; FFmpeg for technical conversion/preview; supplied lawful licensed libraries where needed. These are options to verify for the selected game/OS, not blanket installation requirements. Pin versions and successful invocation/output. Do not install large irrelevant stacks because listed here.

Image generation is used only through an available authorized image tool. A bitmap cannot be silently treated as editable 3D mesh or vector. Generated music/model providers must return sufficient formats, rights and reproducibility for actual use. If the quality floor cannot be reached by current tools, compare legitimate free/local/library route, narrow human craft handoff or explicitly approved paid route before calling the scope complete.

## Work ↔ Codex bridge

If a needed creative capability exists only in Work, create a task packet with exact approved inputs, target/property locks, dimensions/formats/variants, negative constraints, rights requirements, output filenames and return checklist. Execute via the available Work tool, preserve returned original bytes/provenance, then transfer through the shared handoff. Codex validates hashes, formats, rights, scope and engine import before consumption. Never claim Work plugin automatically installed in Codex or that an MCP server materializes files without a verified transfer.

## Budget

Separate subscription allowance, extra API credits, commercial licensing, asset purchases, device/macOS access, store enrollment, hosting/storage/CDN, CI minutes, analytics, ads mediation and maintenance. Default to no new paid services. Existing subscription does not establish third-party commercial rights. Show actual total cost and require explicit authorization before new spend; don't ask again for the same authorized scope.

Suno or equivalent is only a candidate if available, authorized and commercially licensed for the actual output. Recheck current official terms for the exact plan/date/output; do not promise free-plan commercial music or ChatGPT inclusion. Free alternative quality must be demonstrated by actual audition, not asserted as «не гірше Suno».

## Per-item rights

Record creator/source, production method, exact license/terms/date/receipt, commercial/modify/distribute/platform/source-transfer rights, attribution, restrictions, parent assets and transformations. Verify fonts, samples, textures, models, plugins and generated outputs independently. Public preview/download does not imply commercial license. Do not redistribute source libraries whose license prohibits it; use permitted outputs plus verified restore/acquisition instructions and disclose portability limits.

Do not include credentials, tokens, signing keys or private account exports in handoff. Keep provenance honest: licensed track remains licensed, generated output remains generated, adaptation is not original authorship. Ambiguous required rights remain blocker for shipping that item; complete independent production and offer lawful alternatives.

## Reproducibility

Provide pinned tool/config, local relative paths, source dependencies, export/import settings, command or exact manual recipe, input/output hashes, seed where supported, actual log, observed limitations. Re-export in clean working copy when material. Do not run untrusted embedded code from upstream without inspection/isolation; a file inventory validator must not execute generators automatically.

## Descriptor, binding і actual witness

Capability admission перевіряє actual operation schema/catalog/required inputs, formats, parameters that are consumed, versions/host/target, права/privacy/ліміти/cost, witness/freshness й fallback. Catalog-verified або installed статус не означає operation-tested/integrated/native verified.

Вести immutable actual attempts. За unknown outcome зберегти job/requestID і reconcile provider state/output/cost перед retry. Після двох однакових failures класифікувати source ambiguity/capability mismatch/production/integration/perceptual cause; відсутній rig не лікується новим загальним prompt. Новий host bridge pin inputs/toolchain/output contract і return validation; old receipt не підтверджує новий input.
