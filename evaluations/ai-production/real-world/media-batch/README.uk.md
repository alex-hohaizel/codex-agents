# Реальна пакетна перевірка затвердженої кампанії

Ця явно запущена перевірка повторно використовує 20 чинних растрових оригіналів кампанії: англійська/українська × десять матеріалів. Вона зберігає графіку, ідентичність і джерела кампанії. Новий генератор, провайдер, загальний реєстр, встановлений сервіс чи рекламний напрям не додаються. Авторитетними залишаються `marketing/CURRENT_CAMPAIGN.json` і README активної кампанії.

`campaign_batch.py` викликає чинного виробника з приватними шляхами, перевіряє всі 20 джерельних хешів/пар і збіг RGB повних PDF із джерелом, відображає справжнім Poppler усі чотири PDF мов/повних чи компактних форм і фіксує 40 фізичних варіантів сторінок для 20 логічних матеріалів. Контактні аркуші — допомога перегляду, а не додаткові сторінки. Повні PDF зберігають RGB джерела; компактні JPEG навмисно відрізняються пікселями. Растровий текст PDF не має пошукового/доступного текстового шару. Історичну ідентичність кампанії 5.0 збережено без прихованого перейменування на поточну версію інструментарію.

Використовуйте наявний комплектний Python із Pillow/pypdf і наявний `pdftoppm`. Для справжнього запуску нічого не завантажували й не встановлювали. Перед створенням виконайте маркер операції відповідної PDF-навички. З кореня репозиторію, де `$MEDIA` — новий дозволений приватний каталог поза репозиторієм:

```sh
"$PDF_PY" evaluations/ai-production/real-world/media-batch/campaign_batch.py --out "$MEDIA"
```

Спостережена фаза виробництва/відображення тривала 177.42 секунди й зберегла 243418520 байтів у межах 180 секунд/350MiB. Викликів провайдера чи отримання залежностей не було. Завершена або невизначена спроба не перезаписується. Після обробки хеші оригіналів/джерел перевіряються знову; їх зміна скасовує завершення.

До повторного використання збережіть надрукований точний `batch_report_sha256` поза самою квитанцією. Захищений споживач перевіряє цей хеш, усі вихідні байти, джерела й точні 20 логічних/40 фізичних ID та мовні варіанти. Змінена квитанція не переприв’язує старий доказ. Готові матеріали використовуються без нового відображення чи провайдера:

```sh
"$PDF_PY" evaluations/ai-production/real-world/media-batch/cache_guard.py --out "$MEDIA" --expected-report-sha256 "$BATCH_SHA256"
python3.13 -m unittest discover -s evaluations/ai-production/real-world/media-batch -p test_batch_boundaries.py -v
```

Пакет також виконує явно контрольовані випадки несправності/відхилення/скасування/невідомого результату/непослідовного надходження відповідей у несправжнього провайдера. Вони не виконують операцій постачальника, а їх суми не є рахунками. Зберігаються всі запитані ID, повтори/відхилення входять до спроб і вартості, дозволяється лише один явно безпечний повтор підтвердженої невдачі, нез’ясовані/активні/скасовані дії не повторюються, невідома вартість не стає нульовою, а знаменник прийнятих результатів не вигадується. П’ять загальних тестів захищають ці межі та квитанції. Це не доказ якості медіа чи платного провайдера.

Вартість обмежена точно: справжній запуск мав нуль **додаткових оплат провайдера**, але не встановлює безкоштовність початкової графіки чи повну вартість. `full_unit_cost` сирого журналу означає лише суму записаних оплат спроб на прийнятий фізичний варіант. Історична вартість оригіналів невідома; локальні обчислення, енергія й праця виміряні часом/RSS, але не переведені в гроші. Звіт і підсумок панелі зберігають повний TCO невідомим. Знаменники 20 логічних/40 фізичних результатів відокремлені.

Фактичний візуальний перегляд цим виконавцем охоплює чотири контактні аркуші всіх сторінок і повнорозмірні англійський/український рендери сторінки конструкторів. Перевіряються прийнята насичена композиція, ієрархія заголовків/читабельності, ціле кадрування та видимі дефекти відображення. Це не сертифікація кожного дрібного растрового слова, друкарської доступності чи однакових нетекстових пікселів локалізацій. Повне збереження пікселів усередині кожної мови — окремий виміряний доказ. Незалежний перегляд, споживання чинною панеллю та прийняття власником — окремі кроки. Концептуальні зображення не запускають показані продукти.

Аудіо, відео, 3D чи нова генерація графіки не були запитані цією задачею кампанії; вони не перевірені й не прийняті автоматично. Докази SVG/UI/руху застосунку мають окремого власника. Цей обмежений випадок не приймає всі можливі медіа чи всі початкові 29 сценаріїв. [Справжні результати](RESULTS.uk.md) зберігають ці межі.
