# Lower Fen synthetic watershed brief

`E01` Operations staff can select an existing field report, see its source and confidence, and send that particular report to the duty reviewer. A viewer can inspect the evidence and cannot start a handoff. When the report changes after opening, preserve the selected report and explain how to refresh the evidence before repeating the action.

`E02` A public reader can understand three changes along the Lower Fen, open the source notes for the selected change, and return to the account. The public surface uses a reading order built around the river's chronology, without exposing operations controls.

`E03` Preserve the actions and reading order on a wide desktop and a narrow touch viewport. Controls must work with a keyboard, expose the current selection, and report relevant state changes. The evaluation uses fictitious content and local storage only.
