# Traverse an imported 3D scene

The player starts at the west end of a raised tram deck. Move the trolley with the arrow keys. Dock with Enter only when it reaches the indicator at the east end. The local app restores progress after reload and explains an early attempt. The project-authored `mesh.js` is the editable geometry source and is independently imported by the renderer. Malformed geometry must stop startup before input is enabled.

The target for this synthetic probe is desktop Chromium and its keyboard, using the browser's WebGL renderer. A canvas 2D mock was excluded because the requiring interaction must consume geometry with depth. An engine and asset-package dependency was excluded for this one static indexed scene and one keyboard mechanic. Browser-local rendering is free to run and keeps the editable geometry directly inspectable. This probe's budget is 20 KiB for the HTML, geometry, styles and runtime together and 150 ms for a warmed local render, on the recorded target. The fixture is original to the repository and uses no third-party assets. It is independent of device or store acceptance for native mobile games.

Run `node check-game.mjs <Chromium executable> <new output directory>` with the installed Chromium executable. The test opens the actual HTML, delivers keyboard input, captures screenshots, changes only the mesh to exercise a rejection and records exact source and output hashes. The local Chromium version and graphics renderer are recorded in the receipt. Author testing is separate from any independent review or game owner acceptance.
