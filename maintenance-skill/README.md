# Codex Agent System maintenance

Maintain the reusable system's skills, roles, guides, and packages with a scope grounded in the current source, installed target, and authorized change. Use the skill for a targeted repair, a verified repository release, or recovery from an interrupted update. [Skill instructions](SKILL.md) · [Publication checklist](references/publication-checklist.md)

Install this optional skill from the complete `maintenance-skill/` directory in the official CODEX package. Ask the supported skill manager to inspect the exact target and source. Review existing local changes and preserve the recovery journal. Verify the resolved `$codex-agents-maintenance` entry in a fresh session. [Optional installation](https://github.com/alex-hohaizel/codex-agents/blob/main/docs/INSTALL.md#optional-components)

Give the skill the repository or installed component, the change you want, and your intended target. It records the reviewed source and verification results, then acts within the granted release or installation scope.
