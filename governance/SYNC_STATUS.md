- Each run must verify its actual tools, source access and repository permissions. An enabled schedule is not proof that a future executor, connector or host installation is ready.
- Private product data, secrets, chat histories, personal installation receipts and unrelated cached edits are excluded from the reusable repository.
- Production deployment, public visibility, licensing decisions and paid services remain outside this synchronization scope.
