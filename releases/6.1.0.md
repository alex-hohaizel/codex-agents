# Agent System 6.1.0 candidate

Repository edition: **1.4.0-rc.2**. This is a reviewable implementation candidate for the owner's approved AI/data/production passport 0.2. It is not final acceptance of the complete 1.4.0 program. Read the [implementation record](../docs/evolution/2026-11-10/IMPLEMENTATION.en.md) and [migration](migrations/6.1.0.md).

The same 33 core names and two optional sources remain. The twelve host role files retain their models and policies. Existing interface YAML, icon files, bindings and colors remain unchanged. Native project formats, the service API version and database schema are separate from this suite number.

## What changed

- Optional explicit source bindings connect current original files and native requirement IDs to a task. Both the portable helper and service preserve native musts, literal source meaning, explicit decision corrections and deferred work. Required gaps block dependent preparation; legacy projects remain usable with unverified coverage.
- The panel adds readable source/requirement/current-decision/deferred context, a denser project ledger and full mobile navigation. It separates a source record's status from current authority. Loading does not become false zero data; successful retry clears only its own workspace-read error.
- Native history uses bounded turn metadata and item pages. Large conversations no longer require a single full-turn response. Exact observed cursors support further reading; partial, empty or unavailable history remains visible. The transport limit and read-only history boundary remain.
- Seven conditional methods cover DATA, ANALYSIS, LLM, PREDICTION, ADAPTATION, MEDIA and EVALUATION within existing owners. Three self-contained resources describe and check thirteen optional derived artifact types. They are not new skills, background workers, trained models or provider accounts.
- New generated agents carry 15 operating resources and seven local reference links. Historical 5.x and 6.0 packages keep their exact 8- and 12-resource contracts. Installing an old package does not label it as 6.1 adoption. Unknown future contract lines fail explicitly.
- The managed host updater recognizes exact reviewed current/previous blocks and preserves surrounding text. Unknown edits inside the managed block are rejected for reconciliation. Existing role customization guards and protected rollback remain.

The optional orchestrator source is **1.2.0**, maintenance source **1.1.0**, and local service source **0.3.0**. These are source versions. Installation, host discovery, observed running build and product adoption need their own evidence.

An actual macOS probe exposed and then verified a repair for nested native-state write isolation. The candidate preserves existing native reads, denies future nested native-directory writes, and rechecks the bounded inventory before each turn. Unsupported or excessive inventories fail explicitly; this is not an atomic fence against another independent writer. The workbench also uses the fresh workspace's goal and next actions instead of stale portfolio fields. See the exact [API bounds](../apps/agent-atelier/shared/API.md) and [implementation observations](../docs/evolution/2026-11-10/IMPLEMENTATION.en.md).

## Evidence and limits

Actual bounded priority evidence includes source-bound cold recovery, two read-only Codex jobs, real history pages and continuation, rendered desktop/mobile interfaces, seven locales, actual keyboard navigation, and browser loading/failure/retry. Independent code/craft review found defects which were repaired before admission of the affected source. Separate typed-artifact review repaired temporal leakage, in-flight retry, incomplete model bundles, stale evaluation binding and nonfinite JSON handling.

The actual review-analysis case uses 100 public reports and a blind 20-record independent AI comparison. It preserves partial source coverage, disagreement and source/consumer limits. Neither AI agreement nor a schema pass is human ground truth or business accuracy. Full-model training, pre-launch CPA, LoRA, every media/device route, all generated-agent adoption and all 29 complete acceptance cases are not certified by this candidate. The original Svitlobot failure remains unbound. WORK is deferred.

The source package may be inspected and tested as a candidate while those gates stay open. Do not replace the stable running baseline or declare final 1.4.0 adoption merely because source files, archives or CI are available.
