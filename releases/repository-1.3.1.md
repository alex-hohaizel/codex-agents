# Repository 1.3.1 — system audit and proposed AI/data evolution

This documentation release makes the current system and its gaps inspectable. It publishes the [AI/data/ML/creative handbook](../docs/evolution/2026-11-10/README.md), also [in Ukrainian](../docs/evolution/2026-11-10/README.uk.md), a complete current logical-component catalogue, a tracked helper index, primary-source recipes, 23 traced requirements and 24 planned acceptance cases.

The recommendation is passport `ai-data-production-evolution/0.1`: a compatible core extension, seven optional specialists, four optional role profiles and scoped workbench capabilities. It is **awaiting exact owner approval**, not implemented by this release. See [the exact passport](../docs/evolution/2026-11-10/PASSPORT.en.md) and [its status and source bindings](../docs/evolution/2026-11-10/STATUS.json).

## What changes

- New English/Ukrainian handbooks explain every current skill/role and logical service/helper component, activation, source and evidence limits. The helper index retains all429 non-test paths in70 exact-content groups; repeated portable copies are not deleted.
- Source-backed findings separate existing strong context/RAG/media/integration methods from missing specialized data/model execution. App platform/research contradictions are documented for a reviewed future repair.
- The proposal specifies ownership, technical choices, schema/resource/installer consequences, stages, whole-product acceptance, preservation and rollback. It does not reduce the requested full scope to a demo.
- All seven complete installation guides get equivalent documentation-release notices and current repository edition. Existing commands and runtime workflows are preserved. The detailed new handbook itself is EN/UK only.
- Requirements and release metadata distinguish completed audit documentation from the target implementation awaiting selection.
