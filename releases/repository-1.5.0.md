# Repository edition 1.5.0

Edition 1.5.0 groups the updated Codex Agent System sources and stable component version targets. The repository edition describes the combined source snapshot. The component versions and admission state are recorded separately in [current.json](current.json).

The GitHub landing page leads with first use, the capability and tool map, runtime evidence, and component maintenance. The existing bilingual country-neutral showcase stays accessible as a separate illustration of possible workflows.

The reproducible packaging workflow keeps ordinary checks separate from build provenance on the canonical main branch. Only the verified archive, exact source, and applicable native evidence may be promoted to a stable release and applied to Codex. Existing provider scope, project ownership, settings and media identity continue through their own migration and acceptance checks.
