# Repository edition 1.1.0

Date: 2026-11-08. Reusable suite: **5.0.0**, unchanged. Publication evidence is recorded separately in `governance/TASK_CLOSEOUT.json`; a prepared candidate is not a remotely published release.

## Concrete result

This edition finalizes one product-led campaign in **English and Ukrainian**, ten corresponding materials per language. It preserves the exact Ukrainian source cover, its product/studio identities and visual direction. English artwork localizes its corresponding Ukrainian layout. The delivery includes localized descriptions, compact PDFs, portable repository galleries and downloadable full-quality exports. The gallery exposes the exact 33-skill directory when the reader wants more detail.

The selected campaign covers applications, game/studio creation, conversational action, platform depth, automation, both constructors, product lifecycle, continuation and the next real task. The owner authorized retiring prior advertising and finalizing this direction. Superseded concepts, obsolete galleries, draft artwork and the rejected vector replacement are removed from the current tree. Their historical revisions remain in Git history; no repository history rewrite is required.

English is the documentation source. All seven full installation guides remain complete and receive equivalent localized campaign/compatibility entries. Advertising artwork is available only in English and Ukrainian; the other five guide languages link to those editions without claiming additional artwork translations. Current paths and links are recorded in `marketing/CURRENT_CAMPAIGN.json` and the campaign README.

## Compatibility and migration

This is a compatible presentation, documentation and repository-tooling addition. It changes no canonical skill behavior, stable skill names, installed icon identity, generated-agent version, native product schema, production deployment or customer state.

- Existing verified **5.0.0** installations need **no reinstall** for this edition.
- Existing projects continue from their same requirements, accepted decisions, visual identity, native state and checkpoint.
- First installation, actual host discovery and generated-agent adoption remain separate procedures in the full guides and `releases/migrations/5.0.0.md`.
- Apply the [numbered edition migration](migrations/repository-1.1.0.md) to repository references and current advertising work. Do not reset a product, duplicate a global skill or replace its icon merely to obtain new documents.

## Verification and boundaries

The campaign checker verifies both language inventories, exported page counts, artwork/source correspondence and portable gallery structure. Source integrity, visual localization review, translation freshness, archive checks, remote read-back and actual CI each require their own evidence. English lettering changes are intended to preserve composition; a generative image edit alone does not establish pixel identity outside the text. The exact Ukrainian source cover remains hash-guarded.

The illustrated interfaces and sample records are conceptual examples, not evidence of executed purchases, customer results, measured speed or shipped products. The generic [resumable-work contract](../governance/RESUMABLE_WORK.md) protects completed artifact work; it does not claim to fix the host platform's read-only conversation state.

Final generation, QA, package results, removed paths, commit/read-back and CI status are reconciled in [validation](../governance/VALIDATION.md) and `governance/TASK_CLOSEOUT.json`. Mark publication complete only after observing the final remote revision and every affected path.
