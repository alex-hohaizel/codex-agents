# Agent System 5.0.0 — repository edition 1.0.0

> Historical 5.0.0 suite baseline. Current compatible campaign/documentation changes are recorded in `releases/repository-1.1.0.md` and `releases/migrations/repository-1.1.0.md`; they do not require a 5.0.0 reinstall.


Date: 7 November 2026. This repository edition distributes the existing agreed suite `5.0.0`; it is not an additional behavioural upgrade to the 33 skills.

## Changed

The repository now records reusable sources for two constructors, eleven App skills, eleven ChatBot skills and nine Game skills. It adds a human-readable installation and use guide, complete language editions, Work↔Codex continuity templates, release policy, requirements traceability, deterministic source packages and ten visual marketing directions for owner selection.

Canonical skill bytes are preserved from the verified 5.0.0 portable source. Private project-specific agents, old installation backups and historical project evidence are excluded. Source provenance and curated supporting-file integrity are recorded in the kit.

## Compatibility

The suite version stays `5.0.0`. Native project, game runtime and handoff schema versions remain their own contracts. Existing local Codex icons and colours are preserved by the portable updater. Work's host avatar is checked separately from portable icon assets.

The repository does not itself install skills, start another session, add a background executor or migrate a product database. Users with an existing verified 5.0.0 installation can use the new documentation and handoff records without reinstalling; their project still needs a compatibility check before adopting changed workflows.

## Migration

Follow [the 5.0.0 adoption steps](migrations/5.0.0.md). For an already installed 5.0.0 suite, the normal action is to pin this repository revision and reconcile the project context. For earlier 2.3.x/4.3.x installations, use the updater's audit/apply/verify sequence and then perform the project-level adoption steps.

## Evidence

Run `python3 scripts/check_repository.py`, the repository integration tests and `python3 scripts/build_packages.py` from the repository root. Build outputs record exact SHA-256 hashes. These checks verify repository sources and package content; they do not claim host installation or acceptance of a real product. The delivery report records the actual remote revision and completed checks.

## Marketing status

Ten concept directions are available for comparison. Final identity and final promotional production await the owner's choice and corrections. No existing installed skill icon is changed by that choice.
